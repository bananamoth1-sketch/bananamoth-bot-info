# Bananamoth Bot: Privacy Policy

# Last Updated: September 11, 2026

This Privacy Policy explains what information Bananamoth Bot ("the Bot", "we", "us", or "our") may access, store, and use when you interact with Bananamoth Bot, the Bananamoth Bot dashboard, or its features through Discord.

## Information Bananamoth Bot May Access

The information Bananamoth Bot accesses depends on the features being used and the permissions given to Bananamoth Bot.

## Discord Account Information

Bananamoth Bot may receive basic Discord information needed to identify users and provide features.

This may include:

- Discord user ID
- Username or display name
- Avatar information
- Server membership information
- Server roles
- Server permissions
- Server ID
- Channel ID
- Role ID

Bananamoth Bot does not ask for or store your Discord password.

## Server Configuration Information

Bananamoth Bot may store information needed to configure and operate server features, including:

- Server IDs
- Channel IDs
- Role IDs
- Moderation settings
- Verification settings
- Giveaway settings
- Application settings
- Alert settings
- Notification settings

## Messages and Interactions

Some features require Bananamoth Bot to process Discord messages or interactions.

Depending on the feature, this may include:

- Messages sent to Bananamoth Bot
- Command content
- Interaction information
- Message IDs
- Channel IDs
- User IDs
- Information needed to execute a command

Bananamoth Bot does not need to read every message in a server simply because Bananamoth Bot has been installed.

## Reports, Applications, and Verification

If you use reporting, applications, verification, or similar features, information you submit may be processed by Bananamoth Bot.

This may include:

- Your Discord ID
- Your responses
- Server-related information
- Information included in reports
- Information included in applications
- Verification-related information

## Logs and Technical Information

Bananamoth Bot keeps operational information that helps Bananamoth Bot function and allows technical problems to be investigated.

This may include:

- Timestamps
- Error information
- Command activity
- Service activity
- Discord IDs associated with Bananamoth Bot activity
- Technical information related to errors or system activity

## How Information Is Used

Information may be used to:

- Operate Bananamoth Bot
- Respond to commands
- Provide moderation features
- Provide server-management features
- Run verification systems
- Run giveaways
- Manage applications
- Process reports
- Store server configuration
- Send configured alerts and notifications
- Troubleshoot problems
- Monitor Bananamoth Bot performance
- Prevent abuse
- Protect Bananamoth Bot and the dashboard
- Improve Bananamoth Bot

## Discord Data

Bananamoth Bot operates through Discord.

Discord provides information to Bananamoth Bot based on the permissions, intents, interactions, and features available to Bananamoth Bot.

The exact information Bananamoth Bot can access may vary depending on how a server administrator configures Bananamoth Bot.

## Dashboard Login

The Bananamoth Bot dashboard may allow users to sign in using Discord.

Discord handles the login process.

Bananamoth Bot does not ask for or store your Discord password.

The dashboard may receive basic account and server information from Discord to provide dashboard functionality.

## Information You Provide

Some Bananamoth Bot features allow you to provide information directly.

Examples include:

- Giveaway information
- Application responses
- Reports
- Verification information
- Notification settings
- Server configuration

Information provided through these features may be stored so the features can continue working.

## Data Storage

Bananamoth Bot stores certain information so Bananamoth Bot features can function properly.

This may include server configuration, giveaway information, application information, verification settings, alert settings, and operational logs.

Some information may remain stored after a feature is disabled or Bananamoth Bot is removed from a server, particularly information contained in logs, backups, or other operational records.

Information that is no longer needed may be removed over time.

## Sharing Information

Bananamoth Bot does not sell user information.

Information may be processed by services used to operate Bananamoth Bot, such as hosting, storage, or infrastructure providers.

Information may also be processed when necessary to operate Bananamoth Bot, maintain Bananamoth Bot, fix technical problems, or protect Bananamoth Bot from abuse.

## Third-Party Services

Bananamoth Bot depends on Discord and may use other third-party services for certain features.

These services operate independently and may have their own privacy practices and policies.

Bananamoth Bot is not responsible for the privacy practices of third-party services that are not operated by Bananamoth Bot.

## Security

Reasonable measures are used to protect information stored by Bananamoth Bot.

However, no online service, application, or storage system can be guaranteed to be completely secure.

## Removing Bananamoth Bot

Removing Bananamoth Bot from a Discord server stops Bananamoth Bot from operating in that server.

Some stored information may remain after removal, including configuration, logs, backups, or other operational information.

Removing Bananamoth Bot does not necessarily cause previously stored information to be immediately deleted.

## Data Minimization

Bananamoth Bot is designed to use information and Discord permissions needed for the features Bananamoth Bot provides.

Bananamoth Bot does not require Administrator permission simply to operate.

Server administrators can review the permissions requested by Bananamoth Bot during installation.

Bananamoth Bot does not intentionally request access to information that is unrelated to the features being provided.

## Changes to This Privacy Policy

This Privacy Policy may be updated when Bananamoth Bot changes, new features are added, or the way information is handled changes.

The "Last Updated" date at the top of this document will be updated when changes are made.

## Relationship to Discord

Bananamoth Bot is an independent third-party Discord application.

Bananamoth Bot is not operated by, sponsored by, or endorsed by Discord Inc.

Discord has its own privacy practices for information handled by Discord's platform.

Information handled directly by Discord is subject to Discord's own policies and practices.
