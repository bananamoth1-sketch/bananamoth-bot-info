About Bananamoth

Bananamoth is a Discord bot and dashboard that provides server-management, moderation, automation, notification, and configuration features.

Depending on how a server administrator configures Bananamoth, features may include:

Server moderation tools
Member management
Channel management
Role and reaction-role systems
Verification systems
Giveaways
Applications
Reports
Server alerts and notifications
News and update notifications
Event notifications
Fortnite-related alerts and information
Logging and administrative tools
Dashboard configuration and management

Features may change, be updated, or be removed over time.

Using Bananamoth

You should use Bananamoth responsibly and follow Discord's rules while using the Bot.

If you are installing Bananamoth on a Discord server, you should have permission to manage or configure the server.

Discord Permissions

Bananamoth is designed to request only the Discord permissions needed for its features.

Server administrators should review the permissions requested when installing the Bot.

Some Bananamoth features may not work if required permissions are denied or removed.

Server administrators are responsible for configuring the Bot's permissions and deciding which features are enabled.

Attempt to break, overload, or interfere with Bananamoth.
Attempt to gain unauthorized access to accounts, servers, or data.
Abuse moderation, giveaway, verification, application, reporting, or other Bot features.
Attempt to bypass Bot restrictions or security features.
